# Slice run on Modal, 22 Nov 2026

This was a cheap screening round before any full-scale run. It used 96k/12k Q&A pairs built with
`build_qa_text.py --train-docs 12000 --test-docs 1500 --max-context-tokens 512`, and 233k/13k
listwise choice rows (`build_choice_data.py`). Everything ran on the `clm-data` volume. Each `*.json`
in this folder is the `result.json` of the run with that name; `trex.json` has the T-Rex summaries.
Total Modal spend was **$42.33** metered, of which $30 was covered by included credits.

- **tricky:** hard-negative Q&A top-1 on the 7,848-row test.
- **general:** in-batch Q&A top-1.
- **choice_\*:** listwise accuracy on the held-out test, grouped by source.

Latency p50 was 16-17 ms for every head.

**Conclusion:** T-Rex skill comes entirely from the authors' agent post-training. The mid head
fails T-Rex, and the post head is only a tiny weight change away from it. All of our choice
post-training variants lose T-Rex skill, even the gentle run starting from the post head. To beat
CLM on T-Rex, agent or game trajectories (for example the ADP rows) must be part of the
post-training mix.
